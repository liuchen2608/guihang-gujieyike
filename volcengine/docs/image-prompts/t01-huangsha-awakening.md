# T01《黄沙苏醒》最终生图提示词

用途：网页端单人 AI 对话 RPG《归航·蛊界异客》的任务背景图与任务卡封面，横向 16:9。

## 画面需求

生成原创科幻穿越后的沙漠苏醒场景。受损机甲驾驶舱半埋在陌生沙海，一名年轻男性机甲驾驶员刚从破裂舱门中艰难站起，背对或侧背镜头，不展示清晰面孔；画面传达灼热、失血、孤独、陌生与仍未熄灭的归乡希望。

【镜头角度】略高角度从玩家后上方观察，强化人物在陌生沙海中的脆弱与渺小  
【镜头尺寸】28mm 广角电影镜头，横向 16:9，环境空间感强，近景残骸与远方沙丘关系清晰  
【景别】大全景，人物较小，机甲残骸与无边沙漠是主要叙事环境  
【景深】深焦，中景主体和远处地平线均可辨认，最远处被热浪轻微软化  
【电影机/胶片质感】真人电影摄影质感，柔和电影镜头解析力，自然银盐颗粒，高光轻微扩散，边缘自然过渡，不过锐

【主体一——年轻男性机甲驾驶员】  
【核心身份/物种】来自未来机甲世界、意外穿越的年轻男性驾驶员  
【体型/外貌特征】身形修长结实，疲惫受伤，穿深灰黑色破损驾驶服，背对或侧背镜头，脸部不可辨认  
【材质/纹理】驾驶服有磨损织物、哑光复合装甲片、少量沙尘和干涸血迹，腰侧挂着高强度绳索，手上或胸前有一枚小型订婚戒指的低调金属反光  
【动作/姿态】一手扶住破裂舱门，刚从残骸中站起，身体略微弯曲但仍警觉地望向远方

【主体二——受损机甲驾驶舱】  
【核心身份/物种】穿越后严重解体的未来机甲驾驶舱与部分机身残骸  
【体型/外貌特征】巨大但残缺，侧翻并半埋在沙丘，舱门撕裂，外装甲有空间灼蚀痕迹  
【材质/纹理】暗灰金属、烧蚀陶瓷装甲、断裂线缆、少量微弱青绿色应急指示灯，表面被细沙覆盖  
【动作/姿态】静止侧翻，破口朝向人物，风沙正从破裂处穿过

【核心机位位置】机位位于人物左后上方约八米，画面右侧中景安排人物与残骸，左侧与上方保留安静的沙丘和天空负空间，方便网页叠加标题和对话 UI  
【天气与氛围】陌生太阳刚升起的灼热清晨，干燥强风卷起薄沙，空气有热浪扭曲；孤独、危险、克制的希望  
【前景】少量虚化的断裂金属边缘、拖痕和被风吹动的细沙，形成穿越后的破碎感，不遮挡主体  
【中景】玩家与半埋机甲驾驶舱构成唯一清晰视觉中心，微弱青绿色应急灯暗示归航 AI 仍在线  
【远景】层叠而简洁的沙丘、极远处一线难以确认的暗绿色生命信号方向，三个极小且模糊的未知生物痕迹，不明确表现为狼  
【背景】大面积低频沙漠与陌生天空，无城市、无建筑、无蛊虫、无人群，背景干净不抢主体  
【主光源/方向】右上方陌生太阳形成偏暖硬质逆侧光，照亮沙丘脊线与人物轮廓  
【光线软硬质感】阳光偏硬但高光不过曝，阴影边缘清晰；暗部由天空与沙地反射光托起，保留干净层次  
【辅光源/互动光】沙地暖色反射光轻轻照亮驾驶服和残骸暗面，驾驶舱内部微弱青绿色屏幕光分离人物轮廓  
【特效光/气氛光】只有可信来源的热浪、薄沙尘和微弱应急灯，不使用随机光柱、魔法粒子或夸张能量爆发  
【整体色温/基调】暖金黄沙、深灰机甲、少量青绿色科技点光，三色体系  
【色彩饱和体系】整体中低饱和，沙漠暖色清晰但克制，青绿色只作小面积视觉锚点  
【高光与阴影倾向】高光偏暖金色，阴影为干净冷蓝灰和深蓝绿色；黑色材质保留受光面、边缘分离和色相层次  
【对比度与饱和度】中等整体对比、主体局部对比略高；避免油腻 HDR、数码锐化、过度颗粒、泥灰阴影、暗部死黑、彩色噪点、脏斑和颗粒结块

## 约束

原创世界与角色设计；人物面部不可见，保持玩家代入感；画面中不出现文字、标题、UI、Logo 或水印；订婚戒指只是低调细节，不放大；三只远方生物只能是模糊痕迹；细节集中在人物、驾驶舱和拖痕，天空与远景保持简洁；真实透视、自然人体比例、自然手指和肢体；适合深色网页叠加白色文字。

避免直接出现蛊界文字、蛊虫、古装人物、东方建筑、明确狼群、完整可战斗机甲、未来城市、第二颗太阳、夸张霓虹、神秘无来源光、过锐、脏黑、灰雾糊片、密集碎纹理、错误肢体、错误文字和杂乱标识。
