# T09《第一枚道标》最终生图提示词

用途：第二幕收束背景，横向 16:9；沿用主角、希望井和归乡装置视觉。

【镜头角度】眼平略低的仪式性交接视角  
【镜头尺寸】40mm 标准电影镜头  
【景别】全景偏中景，玩家、意志、道标和现实井口可见  
【景深】焦点在双方手间的几何道标  
【电影机/胶片质感】真人电影摄影与实物特效质感

【主体一——现实玩家】保持黑色短发、深灰破损驾驶服和局部砂甲；侧背面，双手接住道标，戒指反光可见。  
【主体二——盗天意志】高瘦不完整人形，由风化青铜片、早期机械关节、蓝灰沙粒与半透明断面组成；无明确脸、无华丽服饰；像程序执行者般递出道标。  
【主体三——第一枚归乡道标】手掌大小的机械星盘，由五段缺口构成，仅第一段发出柔和冷白青绿光；无文字、数字或标签。

【核心机位位置】玩家与意志位于右中，道标为交点；左侧保留消散梦境与雾气  
【天气与氛围】梦境终点；古老、审查、清醒、短暂希望与未知代价  
【前景】蓝灰沙粒和玩家手臂  
【中景】道标交接  
【远景】梦境裂缝后的希望井、长老和乌岩  
【背景】深蓝灰梦境结构与现实石井自然衔接  
【主光源/方向】道标冷白光向上照亮双方轮廓  
【光线软硬质感】半柔光，金属和沙粒边缘清楚  
【辅光源/互动光】现实井口暖火、青绿色生命线和戒指暖金  
【特效光/气氛光】意志边缘散成沙粒，梦境像薄玻璃裂开  
【整体色温/基调】深蓝灰、风化青铜、冷白青绿和暖金  
【色彩饱和体系】整体低饱和  
【高光与阴影倾向】高光冷白，阴影干净深蓝  
【对比度与饱和度】中等对比，交接点局部突出

约束：盗天意志不是完整真人；道标五段中只有一段亮起；不出现文字、UI、Logo、水印；井口人物保持远景。避免明确盗天肖像、王座、神袍、巨大法阵、完整坐标答案、五段全亮和爆炸门户。
