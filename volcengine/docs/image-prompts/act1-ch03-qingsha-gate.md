# 第一幕第三章《青砂部族》最终生图提示词

用途：第一幕第三章专用网页背景，横向 16:9。与包含水轮修复的第四章画面严格区分。

【镜头角度】从寨墙内侧略高处俯看门外，乌岩过肩视角  
【镜头尺寸】30mm 广角电影镜头  
【景别】大全景，玩家较小，寨墙、骨矛和沙海构成权力关系  
【景深】深焦，乌岩骨矛、玩家和远处脚印均可辨  
【电影机/胶片质感】真人电影摄影，柔和解析力、自然银盐颗粒、高光轻微扩散

【主体一——年轻男性机甲驾驶员】保持黑色短发、修长体态和深灰黑破损驾驶服；独自站在门外，身体疲惫略弯，双手抬到可见位置，没有武器。  
【主体二——乌岩】保持晒黑精悍、短发、沙色布巾和实用皮革护具；只出现右侧前景背影与侧脸轮廓，双手稳定握住骨矛，矛尖对准玩家前方地面。

【核心机位位置】乌岩和骨矛位于右侧前景，玩家位于右下中景；左侧大面积沙丘、天空和脚印作为网页文字负空间  
【天气与氛围】烈日下午，寨墙投下清晰阴影；陌生、戒备、脆弱、第一次文明接触  
【前景】乌岩肩部、骨矛和寨墙边缘  
【中景】关闭的厚木石寨门、门外玩家和阴影边界  
【远景】无边沙丘、孤独脚印和微弱热浪  
【背景】简洁暖金天空和低频沙漠  
【主光源/方向】左上方炽热日光照亮门外沙地  
【光线软硬质感】偏硬自然日光，阴影由天空反射托起  
【辅光源/互动光】沙地暖反光与设备极少量青绿色微光  
【特效光/气氛光】真实热浪、风沙和尘埃  
【整体色温/基调】暖金沙海、赭色寨墙、深灰驾驶服、极少量青绿  
【色彩饱和体系】整体中低饱和
