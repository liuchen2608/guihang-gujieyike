# T02《青砂部族》最终生图提示词

用途：网页端任务背景图与任务卡封面，横向 16:9。T01 图片作为主角造型与真人电影摄影风格参考，不复制构图。

【镜头角度】玩家右后方过肩视角，跟随玩家面对乌岩与寨门  
【镜头尺寸】35mm 电影镜头，横向 16:9  
【景别】全景，玩家与乌岩全身可见，寨门、窄水渠和停转水轮交代环境  
【景深】中等偏深，人物清晰，门内水轮与聚落略柔但可辨  
【电影机/胶片质感】真人电影摄影，柔和解析力、自然银盐颗粒、高光轻微扩散、不过锐

【主体一——年轻男性机甲驾驶员】保持 T01 的黑色短发、修长体态和深灰黑破损驾驶服；背对或侧背镜头，双手放在对方可见的位置，疲惫但警觉。  
【主体二——乌岩】晒黑精悍的年轻部族巡逻者，沙色布巾、粗织布、旧皮革和骨质护片；以骨矛斜指玩家胸前，克制警戒而非立即攻击。  
【主体三——青砂部族与水轮】围绕稀缺水源建立的小型西漠聚落；低矮砂岩寨墙、遮阳布棚、浅水渠和停转的木石水轮，轴承断裂，叶片静止。

【核心机位位置】玩家占右侧前景，乌岩位于中景中心，左侧保留较安静的墙面、沙丘与天空负空间供网页叠字  
【天气与氛围】午后热风，绿洲空气略湿润；戒备、试探、文明碰撞  
【前景】玩家肩背与被风推动的细沙  
【中景】乌岩、骨矛和寨门形成核心对峙  
【远景】停转水轮、窄水渠、布棚和少量远观族人  
【背景】低频沙丘和风化岩壁，无宏大城市与华丽宗门  
【主光源/方向】左上方暖色自然日光  
【光线软硬质感】半硬沙漠日光，阴影清晰但不死黑  
【辅光源/互动光】砂岩与浅水渠反光托起暗面，玩家设备保留微弱青绿色光  
【特效光/气氛光】只有风沙和水面反光  
【整体色温/基调】砂岩赭金、旧皮革棕、浅水青绿、少量归航青绿色  
【色彩饱和体系】整体中低饱和，水源与归航光为小面积冷色锚点  
【高光与阴影倾向】高光偏暖，阴影为干净蓝灰与棕灰  
【对比度与饱和度】中等对比，人物局部对比略高

约束：原创人物和聚落；保持 T01 男主造型；不出现文字、UI、Logo、水印；人物手指、骨矛和身体比例自然；部族贫瘠务实但不是肮脏废墟。避免原著知名人物、中式宫殿、宏大宗门、现代城市、枪械、完整机甲、夸张法术、发光蛊虫、过度仙侠服装、脏黑、过锐和杂乱标识。
