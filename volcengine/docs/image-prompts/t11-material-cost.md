# T11《材料的代价》最终生图提示词

用途：第三幕网页任务背景，横向 16:9；沿用玩家、长老、乌岩、砂甲与机甲残骸的材质语言。

【镜头角度】锻造台左前方略低视角  
【镜头尺寸】35mm 电影镜头  
【景别】全景偏中景，玩家、三类材料和外骨骼原型可见  
【景深】焦点在胸口轴承环与玩家注入真元的双手  
【电影机/胶片质感】真人工业电影摄影、自然颗粒、真实火光与金属

【主体一——玩家】保持深灰破损驾驶服与局部砂甲，双手控制熔接和真元输入。  
【主体二——蛊机外骨骼原型】与人体等高的开放式暗银承力骨架；琥珀蜕壳护片、青铜轴承胸环和少量青绿色传感线；四肢接口外露，尚未完成。  
【主体三——乌岩与守卫】站在工坊入口监督，不参与操作。

【核心机位位置】玩家与外骨骼位于右侧；三种材料沿锻造台形成视觉路径；左侧保留暗墙、烟气和空台面  
【天气与氛围】废弃工坊；炎热、专注、危险、工程突破与政治监视  
【前景】锻锤、星铁砂小碟和冷却水滴  
【中景】玩家、琥珀蜕壳、暗银星铁砂、青铜轴承与外骨骼  
【远景】乌岩、守卫与工坊门  
【背景】低频石墙、木梁和简洁熔炉  
【主光源/方向】右下方锻炉暖橙火光  
【光线软硬质感】半硬火光，阴影由门口日光托起  
【辅光源/互动光】淡金真元、青绿色线路和蓝灰水反射  
【特效光/气氛光】真实火星、蒸汽和热浪  
【整体色温/基调】暖橙、暗银、琥珀、青铜和少量青绿  
【色彩饱和体系】整体中低饱和  
【高光与阴影倾向】金属高光偏暖，阴影深棕与蓝灰  
【对比度与饱和度】局部中高对比

约束：三种材料可区分；外骨骼是开放骨架；材料取得方式保持中立；不出现文字、UI、Logo、水印或多余蛊虫。避免全身超级装甲、激光焊枪、机器人流水线、魔法法阵和可读蓝图。
