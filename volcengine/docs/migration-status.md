## 边界

- 云服务和模型调用的预算、凭据与费用预警需由部署者单独配置；公开源码不附带这些配置。
- 基准：原项目已发布提交 `8a93d4061315e5f0aaf178f458190b6bec393288`。不包含 `web/` 中尚未发布的移动端等改动。
- 此目录是独立迁移副本；不覆盖原 Sites 项目，不改变原站访问权限。
- 复用已有北京地域 serverless 网关，仅新增归航应用的服务/路由，不修改其他应用及其路由。

## 适配方案

- 用标准 Next.js Node 服务替代 Cloudflare Worker 构建，输出 standalone。
- RAG Markdown 使用构建期文本模块打包，不依赖线上文件系统路径。
- 用私有 TOS 文档保存玩家存档；状态与对话同一次条件写提交。
- `ifMatch` 防止并发覆盖，创建时 `forbidOverwrite` 防止并发首次写互相覆盖。
- 存储桶必须从未开启版本控制；开启或暂停版本控制均拒绝写入。
- 不以函数临时磁盘或内存作线上存档。测试内存实现仅在测试文件中。
- GitHub 登录使用同一账户资料、独立登录会话；原站 Cookie 不能自动跨域。
- 健康接口缺少存储配置时返回 503，不宣称可玩。

## 费用防护与限制

- 当前规格 0.5 vCPU / 1024 MiB，按需实例，最小 0、最大 1。没有购买预留实例或资源包。
- `vefaas fn scale --id hh7mqjws` 实际读回：`MinInstance: 0`、`MaxInstance: 1`、`ReservedFrozenInstance: 0`、`MemoryMB: 1024`。
- 当前云端覆盖为全站每天 50、每月 500 次模型请求（源码默认仍为 100/1000）；计数持久化、并发原子更新。失败请求也消耗额度，避免异常重试失控。
- 达到模型额度时沿用游戏现有本地叙事降级，不无限调用模型。
- 单玩家最多 20 个新存档；单玩家文档不超过 2 MiB。超额拒绝写入，不删除旧内容。
- 模型次数限制不是人民币限额。网关流量、请求、函数时长和异常访问仍可能计费，不能将其宣称为硬性费用封顶。
- 预算含基础设施及模型调用时，应预留余额，先小范围试玩。未核验费用及云端预警前，不扩大公开流量。
