# 手机端与微信内适配：实现与验收记录

日期：2026-08-27。状态：本地实现与模拟验收完成；用户已明确授权将手机适配版发布到现有公开网址，供手机测试。微信真机和中国大陆网络验收待完成，不代表这些环境已经通过验收。

## 本次实现

- 保留 React / Vinext / Sites、原网址规划、剧情与存档数据结构；没有新增微信登录、邀请码权限、离线模式或 PWA。
- 720px 以下采用单列对话、顶部幕/章/当前目标、底部输入；721～1050px 保留任务侧栏，状态改为菜单；更宽屏幕保留三列。
- 菜单收纳状态、物品、治疗、行动档案和音乐。弹层在 body 层渲染，互斥切换、锁定背景交互、圈定焦点并恢复焦点/页面位置。
- 以动态视口和 VisualViewport 处理可见高度与偏移；支持底部安全区域、短屏和横屏；放大文字时不强制重置视口。
- 手机回车换行、点击发送；电脑 Enter 发送，Shift+Enter 换行，中文组词和 keyCode 229 不触发提交。
- 离底部 96px 以内跟随新消息；浏览历史时保持阅读位置，出现“有新消息”按钮。背景图不能拦截交互。
- 音乐保持单一音频实例；只在玩家点击后播放。手机放进菜单，非游戏页入口在普通文档流中，不覆盖表单。平台控制音量时提示使用系统音量键。
- 页面恢复可见、pageshow、网络恢复时读取服务端存档。发起回合用同步锁防止连续点击；未知请求结果和版本冲突必须核对后继续，不自动重发；保留尚未确认的输入。
- GitHub 取消/失败后可以返回服务端验证过的存档或匿名开局，重试携带当前匿名身份。提示微信与外部浏览器不会共享匿名存档。
- 本地存储不可用时明确提示，不创建无法保存的新身份。现有匿名身份与旧存档结构未改。
- 结算页的“继续第三幕”先回到游戏页，由同一套核对与提交逻辑完成续接。

## 图片

24 张 PNG 原画原样保留；手机版本位于 `public/images/mobile/`，960px 宽 WebP，总计 1,468,128 字节，单张约 38～97KB，均低于 400KB。与原图集合相比体积减少约 97.2%；这不是首屏流量的对比，因为原实现也只使用当前节点图片。

场景配置增加可选 `mobileSrc`、`mobilePosition`。CSS 按屏宽只引用当前节点的一个背景资源；图片失败保留深色底，对话不依赖图片加载。为沙海、部族入口等五个节点单独设置手机焦点，保留关键人物。全图与竖屏裁切预览已目视检查；原图未被裁切或替换。

手动重新生成时使用现成的 sharp 模块，仅作为资产工具，不是运行依赖：

```sh
node --experimental-strip-types scripts/prepare-mobile-images.mjs /absolute/path/to/sharp
```

脚本会生成手机图片及 `outputs/mobile-scenes-contact.jpg`、`outputs/mobile-scenes-portrait.jpg` 检查图；outputs 不进入发布内容。

## 存档并发补强

原实现先读取版本、再条件更新，却无条件插入消息；两个请求同时通过读取检查时，失败的更新仍可能留下多余消息。

本次保持接口、数据库结构不变：在同一 D1 事务批次内，全部消息写入都检查拥有者和预期版本，最后推进版本，并检查实际变更行数。未获得该版本的请求返回原有 `VERSION_CONFLICT`。SQLite 单元测试及本地 D1 并发接口测试均覆盖这个路径。

## 发布前必须完成：真机记录

使用可供设备访问的隔离测试环境或经确认的可信局域网预览；不要把含调试入口的开发服务直接开放到公网。当前 localhost 链接不能直接在别人的手机上使用。

分别记录：iPhone 型号 / iOS / Safari / 微信版本，安卓型号 / 系统 / Chrome / 微信版本，网络运营商、Wi-Fi 或蜂窝网络，以及测试日期。以下四类设备入口均未完成真机验收：

- [ ] iPhone Safari
- [ ] iPhone 微信
- [ ] 安卓 Chrome
- [ ] 安卓微信

每一项都执行：

1. 链接进入 → 匿名开局 → 三幕剧情 → 结算 → 反馈页；录下错误或遮挡现象。
2. 原生中文键盘选字、换行、长文编辑；反复开关键盘、滚动地址栏、横竖屏切换、文字缩放；发送和关闭始终可触及。
3. 回看历史时收到回复不跳位置；图片加载失败仍可对话，24 个节点无错图或重复引用。
4. 发送中切后台、锁屏、断网、恢复；确保不重复结算，原输入保留，核对完成前不能再次发送。
5. 刷新、关闭微信页面再打开，验证同一浏览器匿名续玩；换浏览器明确不会自动继承匿名存档。
6. GitHub 实际成功授权、取消和失败回退；在同一账号成功登录后验证跨设备续玩。真实第三方授权尚未由本次自动测试完成。
7. 手动音乐播放、暂停、系统音量键及后台恢复。不能正常播放时不影响对话，并有提示。
8. 中国大陆实际 Wi-Fi 和蜂窝网络下验证域名、图片与生产 AI 请求的可达性。把 AI 服务耗时与页面渲染耗时分开记录；访问受阻不能用布局修改代替解决。
