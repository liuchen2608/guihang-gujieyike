# 第三幕第三章《材料的代价》最终生图提示词

用途：第三幕第三章专用网页背景，横向 16:9。与第四章《第一次铸造》的工坊画面严格区分。

【镜头角度】石桌一端略低的侧向观察视角  
【镜头尺寸】45mm 标准电影镜头  
【景别】全景偏中景，玩家、长老、乌岩、守卫、石桌和仓门可见  
【景深】焦点落在三种材料与长老摊开的手  
【电影机/胶片质感】真人政治冒险电影摄影、自然颗粒、夕阳高光轻微扩散

【主体一——玩家】保持黑色短发和深灰破损驾驶服；一手靠近自己的机甲工具盒，正在权衡条件，没有伸手抢夺材料。  
【主体二——青砂长老】保持清瘦年迈、灰白头发与胡须、沙白和暗青布袍；站在桌对面，一手摊开提出交换条件。  
【主体三——乌岩与守卫】乌岩侧身观察双方；守卫竖持骨矛守住半开仓门，不主动攻击。

石桌上分开放置三种尚未交付的材料：琥珀色砂甲蛊蜕壳、浅石碗中的暗银星铁砂、磨损但可修复的青铜水轮轴承。

【核心机位位置】谈判桌和人物位于右侧与中央，左侧保留砂岩墙、沙尘与仓院空地  
【天气与氛围】西漠傍晚；利益交换、有限信任、诱惑和潜在冲突  
【前景】绳结、木箱边缘和玩家工具盒  
【中景】三种材料、玩家、长老与双方手势  
【远景】乌岩、半开仓门、守卫和防御工事  
【背景】砂岩仓库、粗木门和低矮寨墙  
【主光源/方向】左后方夕阳暖色侧逆光  
【光线软硬质感】半柔夕阳，阴影由砂岩反射托起  
【辅光源/互动光】琥珀、冷银和氧化青铜的真实材料反光  
【特效光/气氛光】只有真实尘埃，不使用魔法发光  
【整体色温/基调】铜金、赭色、暗银、旧青铜和深灰  
【色彩饱和体系】整体中低饱和  
【高光与阴影倾向】高光偏暖，阴影蓝灰与棕灰  
【对比度与饱和度】中等对比

约束：三种材料清楚且仍未交付；交易、援助、偷取三条路线保持中立；不出现外骨骼、锻造、熔炉、火花、真元注入、偷窃动作、文字、UI、Logo 或水印。避免完整机甲、现代商店、金币堆、法阵、魔法光和原著知名人物。
