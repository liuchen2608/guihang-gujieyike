# T05《意识重叠》最终生图提示词

用途：第二幕网页任务背景，横向 16:9；沿用第一幕主角、破损驾驶服和真人电影摄影风格。

【镜头角度】隔着破裂舱盖观察两段意识重叠的正面偏侧视角  
【镜头尺寸】35mm 标准广角  
【景别】中远景，两名驾驶员上半身和双层驾驶舱清楚可见  
【景深】焦点在错位叠合的两只手与裂纹交点  
【电影机/胶片质感】柔和真人电影摄影、自然颗粒、高光扩散；通过空间错位表现梦境

【主体一——现实玩家】保持黑色短发和深灰破损驾驶服；一手按住舱盖，一手握订婚戒指，面孔仅为模糊侧影。  
【主体二——本杰孙】年龄相近，略长头发，穿更古老的灰白机甲驾驶服；动作近似但不完全同步，面孔被反光与裂纹遮挡。

【核心机位位置】两人位于右中区域，左侧保留蓝黑井壁与雾化负空间  
【天气与氛围】蓝色梦境、记忆失重、身份不稳定、幽静压迫  
【前景】破裂透明舱盖、水滴和漂浮细沙  
【中景】两名驾驶员的手、肩部和错位舱体  
【远景】半边希望井石环、半边古老机甲舱骨架  
【背景】深蓝灰低频空间  
【主光源/方向】上方井口柔白光与侧后方冷蓝设备光  
【光线软硬质感】半柔光，裂纹高光清晰，暗部由环境反射托起  
【辅光源/互动光】青绿色现代设备光与蓝白旧设备光  
【特效光/气氛光】水雾、细沙、玻璃反射和轻微空间折射  
【整体色温/基调】深蓝灰、冷白、青绿色与戒指暖金  
【色彩饱和体系】整体低饱和，戒指为唯一暖色情感锚点  
【高光与阴影倾向】高光冷白，阴影干净深蓝灰  
【对比度与饱和度】中等对比，避免 HDR、过锐与彩色噪点

约束：两名男性是不同个体但形成记忆镜像；不出现文字、UI、Logo、水印；左侧保留网页文字区；手指自然。避免成熟盗天形象、仙宫、法阵、光翼、满屏代码、重复脸和脏黑。
