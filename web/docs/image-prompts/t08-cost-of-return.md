# T08《回家的代价》最终生图提示词

用途：第二幕网页任务背景，横向 16:9；沿用主角、未婚妻、本杰孙与蓝色梦境视觉。

【镜头角度】低角度三分之四后侧视角  
【镜头尺寸】28mm 广角电影镜头  
【景别】全景，玩家、环形装置、导管、空石座和故乡影像分层清楚  
【景深】焦点在扯断导管的手与订婚戒指  
【电影机/胶片质感】真人科幻悬疑电影摄影、自然颗粒、真实材质

【主体一——现实玩家】保持破损驾驶服与局部琥珀砂甲；一手扯断暗红生命导管，一手按胸口确认身份；痛苦但坚定。  
【主体二——归乡装置】古老石质与早期机械结构混合的巨大圆环；中央只显示模糊故乡影像，不是真正开启的门户。  
【主体三——未婚妻影像与本杰孙影子】未婚妻保持固定工程制服形象；本杰孙只是一道试图覆盖玩家的蓝黑错位影子。

【核心机位位置】玩家与装置位于右侧和中央，左侧布置低频石壁、断导管与暗雾  
【天气与氛围】封闭梦境试炼室；诱惑、痛苦、道德压力和身份抵抗  
【前景】断裂导管、琥珀光尘和砂甲手臂  
【中景】玩家与归乡圆环  
【远景】五个空置石座和未婚妻影像  
【背景】深蓝灰古老石室  
【主光源/方向】圆环中心柔白冷光  
【光线软硬质感】半硬逆光，暗部有石壁反射  
【辅光源/互动光】暗红琥珀导管光、青绿色腕部光与戒指暖金  
【特效光/气氛光】导管逸散光尘、梦境裂纹和空间折射  
【整体色温/基调】深蓝灰、冷白、暗红琥珀、青绿与暖金  
【色彩饱和体系】整体低饱和  
【高光与阴影倾向】高光冷白，阴影透明深蓝灰  
【对比度与饱和度】中高局部对比，整体克制

约束：装置只是诱惑和测试；五个石座空置，不出现受害者；玩家拒绝牺牲他人；不出现文字、UI、Logo、水印。避免血池、尸体、血腥抽取、恶魔祭坛、成熟盗天实体和可读数据。
