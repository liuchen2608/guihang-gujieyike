# T10《井口审判》最终生图提示词

用途：第三幕网页任务背景，横向 16:9；沿用玩家、青砂长老、乌岩、希望井和道标造型。

【镜头角度】玩家左后方略低视角  
【镜头尺寸】35mm 电影镜头  
【景别】全景，玩家、长老、乌岩、守卫环与希望井分层清楚  
【景深】焦点在玩家手中道标与长老的审视  
【电影机/胶片质感】真人政治悬疑电影摄影、自然颗粒、晨雾高光扩散

【主体一——玩家】穿深灰破损驾驶服和局部琥珀砂甲；单膝撑地，一手握五段中只亮一段的道标，不主动攻击。  
【主体二——青砂长老】清瘦年迈，穿沙白与暗青实用布袍；站在石阶上审视玩家，并示意守卫暂缓。  
【主体三——乌岩与守卫】乌岩横持骨矛作为双方缓冲；四至五名守卫半圆包围但没有立即攻击。

【核心机位位置】人物集中在右侧和中央，左侧保留晨雾、石墙和天空负空间  
【天气与氛围】西漠清晨；审判、怀疑、克制、争取合作  
【前景】湿润井沿、玩家手臂和消散的蓝灰梦境沙尘  
【中景】玩家、道标、乌岩和长老  
【远景】守卫、部族墙体和工坊轮廓  
【背景】简洁砂岩与晨空  
【主光源/方向】左上方暖色晨光  
【光线软硬质感】晨雾过滤的半柔光  
【辅光源/互动光】井内冷蓝、道标青绿与砂岩暖反射  
【特效光/气氛光】少量水汽、梦境沙尘和道标微光  
【整体色温/基调】砂岩暖金、暗青布袍、深灰驾驶服与冷蓝线索  
【色彩饱和体系】整体中低饱和  
【高光与阴影倾向】高光偏暖，阴影干净蓝灰  
【对比度与饱和度】中等对比

约束：审判结果未定；道标仅一段亮；守卫不攻击；不出现文字、UI、Logo、水印。避免成熟盗天、王座、法庭文字、华丽仙宫、法术爆炸和血腥冲突。
