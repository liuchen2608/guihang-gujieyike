# T04《失控的胜利》最终生图提示词

用途：网页端任务背景图与任务卡封面，横向 16:9。前三张图片作为主角、乌岩、希望井、砂甲蛊效果和真人电影摄影风格参考。

【镜头角度】贴地低机位，从倒地少年附近仰视玩家与逼近沙狼  
【镜头尺寸】24mm 广角电影镜头  
【景别】全景动作场面，玩家、少年、乌岩、狼群和希望井有清楚层级  
【景深】玩家和最近沙狼最清晰，井口裂缝与冷青反光仍可辨  
【电影机/胶片质感】真人电影摄影、柔和解析力、自然颗粒、真实风沙运动、高光不过曝

【主体一——年轻男性机甲驾驶员】保持黑色短发和深灰黑驾驶服；左臂、肩部和小腿局部覆盖粗粝琥珀岩砂护甲。以砂甲手臂挡住扑来的沙狼，另一只手和身体保护倒地少年；动作精准得略显非人，腰侧设备发出克制的不稳定青绿色脉冲。  
【主体二——乌岩与部族少年】乌岩在玩家侧后方用骨矛牵制另一只狼，同时担心玩家的异常状态；普通少年伏低护住头部，没有明显伤口。  
【主体三——沙狼群】三至四只适应西漠的瘦长沙色狼，短毛、真实爪牙和肌肉；最近一只扑向砂甲盾，其他狼从侧面包围，不带发光符文。

【核心机位位置】玩家与扑来的狼位于右侧中景，左侧和左上保留风沙天空负空间供网页叠字，希望井位于后方视觉线上  
【天气与氛围】黄昏沙暴；英勇、危险、胜利即将失控  
【前景】碎石、少年手臂和冲击扬沙，无血腥特写  
【中景】玩家砂甲盾与扑来的沙狼  
【远景】乌岩、部族墙体、撤离族人和震裂的希望井石环；井下只有细小冷青机械反光  
【背景】低频岩壁、风沙天空和简洁聚落轮廓  
【主光源/方向】左后方低位夕阳穿过沙尘形成暖色轮廓光  
【光线软硬质感】沙尘过滤的半硬光，暗部有环境反射层次  
【辅光源/互动光】砂地暖反光、设备青绿色光和井下冷青反光  
【特效光/气氛光】真实风沙、撞击砂粒和设备脉冲光，无能量炮和魔法爆炸  
【整体色温/基调】夕阳铜金、风沙棕、深灰驾驶服、少量青绿与冷青  
【色彩饱和体系】整体中低饱和，砂甲暖色与归航冷色形成克制对比  
【高光与阴影倾向】高光偏暖铜金，阴影为干净蓝灰与深棕
