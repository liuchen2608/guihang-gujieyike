# T03《无窍者启窍》最终生图提示词

用途：网页端任务背景图与任务卡封面，横向 16:9。T01、T02 作为主角、乌岩、青砂部族环境和摄影风格参考。

【镜头角度】略低于眼平的三分之四侧面视角，庄重但不神化玩家  
【镜头尺寸】40mm 标准电影镜头  
【景别】全景偏中景，玩家全身和井台可见  
【景深】焦点落在胸前希望蛊、掌心砂甲蛊和驾驶服接触区域  
【电影机/胶片质感】真人电影摄影、柔和解析力、自然颗粒、高光轻微扩散

【主体一——年轻男性机甲驾驶员】保持黑色短发和破损深灰驾驶服；身体因痛苦略微前倾，一手按住胸口，另一手托住砂甲蛊，仍保持清醒与自主控制。  
【主体二——希望蛊与砂甲蛊】希望蛊为细小柔白半透明、近似光蝶但有真实生命质感；砂甲蛊为拇指大小、琥珀砂色甲虫状实物。希望蛊停在胸前，砂甲蛊伏在掌心，少量砂粒护甲纹路与手套接口相连。  
【主体三——青砂长老与乌岩】长老年迈清瘦、穿实用沙白和暗青布袍；乌岩保持晒黑精悍、沙色布巾与旧皮革护具。两人在井台边缘观察。

【核心机位位置】玩家位于右侧视觉中心，左侧保留石壁、井雾和暗色负空间供网页叠字  
【天气与氛围】半地下希望井，空气清凉、有少量水汽；神秘、疼痛、克制突破  
【前景】低矮石栏、湿润砂砾和旧绳结  
【中景】玩家、两只蛊虫和局部砂甲纹路  
【远景】长老、乌岩、古老井壁和少量部族灯火  
【背景】风化圆形岩壁、简洁水纹和粗糙石阶  
【主光源/方向】井口上方自然天光从右上斜落  
【光线软硬质感】半柔光，暗部由石壁和水面反射托起  
【辅光源/互动光】希望蛊柔白微光、砂甲蛊琥珀反光和极少量设备青绿光  
【特效光/气氛光】少量井雾与悬浮细沙，无无来源光柱  
【整体色温/基调】冷灰石壁、琥珀砂甲、柔白希望光、少量青绿色  
【色彩饱和体系】整体中低饱和，蛊虫与接口为局部颜色焦点  
【高光与阴影倾向】高光柔白偏暖，阴影干净蓝灰  
【对比度与饱和度】中等对比，避免油腻 HDR、死黑、泥灰和噪点

约束：保持人物和环境连续；蛊虫尺寸真实克制；启窍表现为痛苦的未知生理变化而非成神；不出现文字、悬浮 UI、Logo 或水印；人物比例与手指自然。避免巨大光翼、法阵、满墙符咒、仙宫、御剑、爆炸法术、完整机甲、现代实验室和原著知名人物。
